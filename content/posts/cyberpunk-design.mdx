# 赛博朋克美学：设计灵感与实现

赛博朋克是一种独特的视觉风格，融合了高科技与低生活的对比美学。

## 核心元素

### 1. 霓虹色彩

赛博朋克的标志性色彩包括：

- **青色 (Cyan)** - #00f5ff
- **品红 (Magenta)** - #ff006e
- **紫色 (Purple)** - #9d4edd
- **霓虹绿** - #39ff14

### 2. 发光效果

使用 CSS 实现霓虹发光：

```css
.neon-text {
  text-shadow:
    0 0 5px #00f5ff,
    0 0 10px #00f5ff,
    0 0 20px #00f5ff,
    0 0 40px #00f5ff;
}
```

### 3. 故障艺术 (Glitch)

故障效果通过 CSS 动画实现：

```css
.glitch {
  animation: glitch 1s linear infinite;
}

@keyframes glitch {
  0%, 100% { transform: translate(0); }
  20% { transform: translate(-2px, 2px); }
  40% { transform: translate(-2px, -2px); }
  60% { transform: translate(2px, 2px); }
  80% { transform: translate(2px, -2px); }
}
```

## 设计原则

### 对比与层次

- 深色背景配合明亮的霓虹色
- 使用渐变创造深度感
- 透明度和模糊效果增加层次

### 几何与网格

- 使用网格线作为背景元素
- 几何形状作为装饰
- 直线与锐角的运用

### 动态与交互

- 微妙的动画效果
- 悬停状态的视觉反馈
- 扫描线和闪烁效果

## 实际应用

在这个博客中，我应用了以下赛博朋克元素：

1. **粒子背景** - 营造数字空间感
2. **扫描线** - 模拟 CRT 显示器效果
3. **霓虹边框** - 突出重要元素
4. **故障文字** - 标题的视觉冲击
