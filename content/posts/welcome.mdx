# 欢迎来到我的赛博朋克博客

你好，欢迎来到我的数字空间！这是一个融合了赛博朋克美学与现代 Web 技术的个人博客。

## 为什么选择赛博朋克风格？

赛博朋克不仅仅是一种视觉风格，它代表了对未来的想象，对技术与人文的思考。霓虹灯光、故障艺术、数字化的一切——这些元素构成了一个独特的视觉语言。

## 技术栈

这个博客使用了以下技术构建：

- **Next.js 14** - React 框架，支持 App Router
- **Tailwind CSS** - 原子化 CSS 框架
- **Framer Motion** - 动画库
- **MDX** - Markdown + JSX

## 功能特点

### 视觉效果

- 霓虹灯发光效果
- 故障艺术动画
- 粒子背景
- 扫描线效果

### 交互功能

- 文章点赞
- 评论系统
- 社交分享
- 全文搜索

### 阅读体验

- 阅读进度条
- 目录导航
- 主题切换
- 响应式设计
